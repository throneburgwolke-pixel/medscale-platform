# 量表核对报告

更新日期：2026-10-23；本轮查证开始于2026-10-22。

## 当前状态与限制

当前代码含101个模板、77条目录记录。结构测试、独立手算用例和浏览器流程测试不等于所有量表已经完成医学、中文版本及版权审校。现有模板的逐项文本和授权审校、其余扩充清单仍未全部完成，不能称为“全网量表已经全部核对”或“所有量表均可直接临床使用”。

此前的并行研究未返回可核查交付物。本轮改用原始评分表、官方指南和有出处的资料逐项核对。未核实的版本不凭记忆新增，不把网页上能下载等同于允许在公开平台电子化分发。

`licenseTier` 的既有批量赋值主要依据旧说明文字，不能视为权利方授权证明。`registration` 表示仍须遵守注册、培训、使用场景等条件；是否允许电子化和公开分发须另行核实。商业授权或正文未获准的模板仅保留结构，并通过发布守卫阻止占位正文发布。

## 新增NIHSS记录模板

新增NIHSS的15个计分项目，总分0–42，用于受训评估者在完成规范检查后录入评分。必须使用官方检查指导语和语言/构音测试材料，平台不以任意文字替代正式刺激材料。另新增Hachinski缺血指数（13项，0–18分，≥7支持血管性痴呆）、SOFA、改良Geneva和Glasgow-Blatchford：SOFA按六器官系统原始0–4档记录；Geneva按8项客观变量0–22分；GBS按性别、尿素、血红蛋白、生命体征与病史用具名公式计算0–23分。

依据：[NINDS NIHSS入口](https://www.ninds.nih.gov/health-information/stroke/assess-and-treat/nih-stroke-scale)、[NIHSS评分提示](https://crsn.ca/images/NIHSS_ScoringTips_Brochure_Nov2023.pdf)、[SOFA评分表与综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC9837980/)、[改良Geneva规则](https://www.mdcalc.com/calc/1750/geneva-score-revised-pulmonary-embolism)、[Glasgow-Blatchford评分表](https://pmc.ncbi.nlm.nih.gov/articles/PMC4423275/)。

提供截肢、关节融合或插管等情况下的UN记录选项；UN不会被算成0分，不输出完整总分。0分不能排除卒中，尤其后循环卒中；分数分层不能代替卒中团队的临床决策。

依据：[NINDS官方入口](https://www.ninds.nih.gov/health-information/stroke/assess-and-treat/nih-stroke-scale)、[Canadian Stroke Research Network 2023评分说明](https://crsn.ca/images/NIHSS_ScoringTips_Brochure_Nov2023.pdf)。中文文本是评分记录说明，不宣称为经正式验证的整套NIHSS中文测试材料。

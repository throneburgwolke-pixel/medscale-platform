# 医学量表与问卷平台 · 使用说明

本平台用于把量表/问卷发放出去、回收数据并完成计分与统计分析。全部代码零第三方依赖，
数据只保存在部署机器上，不经过任何第三方服务。

运行环境：Node.js ≥ 22.5（使用内置 `node:sqlite`）。

本文面向使用者；只有要改代码或换一台机器部署时，才需要再看仓库根目录的 `README.md`
（环境变量、测试怎么跑、必须遵守的工程约定）。

---

## 一、启动与访问

```bash
cd medscale
node server.js
```

- 默认端口 `5173`，地址 `http://localhost:5173`。
- **端口被占用时不会顺延到其他端口**，而是直接启动失败并提示改用 `PORT=8080 node server.js`。
  这样命令行显示的地址与实际地址始终一致，扫码链接不会失效。
- 默认只监听 `127.0.0.1`，即仅本机可访问。需要手机扫码填写时，用同目录的
  `启动平台.command` 启动，或以 `MEDSCALE_LAN=1 node server.js` 启动；
  命令行会打印局域网地址（如 `http://192.168.1.5:5173`），受试者与本机连同一 WiFi 即可填写。
  开放局域网意味着同网段设备都能访问该服务，请在可信网络内使用。
- 停止服务：关闭窗口或 `Ctrl + C`，数据不会丢失。
- 数据文件位置：`data/app.db`（可用环境变量 `MEDSCALE_DB` 指定别的路径）。
  启动横幅会打印实际生效的数据文件路径与备份目录。
- 要用 HTTPS 域名发布到公网（同事在院外也能访问）：见仓库根目录 `README.md` 第六节，
  要点是「反向代理终止 TLS + 应用仍只听本机 + 开账号走邀请码」，数据依旧只在那台机器的
  `data/app.db` 里。

## 二、账号、注册与权限

- **第一个注册的账号自动成为管理员**：`node server.js` 后打开首页 → 注册，第一个账号不需要邀请码。
- 之后默认走**邀请码**：管理员在「系统设置 → 谁能开账号」生成 8 位邀请码（可设可用次数与
  有效天数），把码抄给同事或贴到群里，对方在首页「邀请码注册」里自己设口令开号。
  码用完、过期或随时点「吊销」都会失效；同一张码可以多人共用。
  同一页还能把策略改成「关闭自助注册」（只由管理员在「用户管理」创建账号）或
  「开放注册」（任何人可自助注册，公网环境不建议长期开着）。
- 管理员登录入口：首页 → 登录 → 「用管理员密码登录」，使用系统管理员口令进入。
- **请立即修改初始管理员口令**：系统设置 → 修改管理员密码。首次启动会**自动生成随机初始口令**，
  打印在启动日志并写入数据目录的「管理员初始口令.txt」（改密后自动删除）；部署者也可以用
  环境变量 `MEDSCALE_PASSWORD` 自行指定。受试者看不到，本文也不写。
  口令仅以加盐哈希保存在本机，明文不落库；修改后所有会话失效，需要重新登录。
- **数据按创建者隔离，账号之间互不可见**：每个人只看得见自己创建的量表、调查、随访
  及其答卷；别人的看不见，未登录的访客更看不到。管理员可查看全部。
  内置量表模板是共享题库，不含任何答卷数据，对所有人开放。
  没有归属的历史遗留数据（以及用「管理员密码」这种不含账号身份的会话所建的内容）
  默认只对管理员可见，不会自动开放给其他账号。
- 一份调查的统计报告、CSV / JSON / SPSS 导出、变量说明和单份答卷，与调查本身
  使用同一套归属校验——能看到调查，才可能看到它的数据。
- 忘记某个账号密码：由管理员在「用户管理」中重置。

## 三、量表库与授权标注

- 「量表库」提供数十个内置量表模板，覆盖情绪与心理、睡眠、认知与老年、康复与疼痛、
  护理评估、营养、呼吸与心血管、消化与泌尿、用药与依从性、成瘾行为、生活质量等方向。
- 每张卡片都有许可标签，悬停可看完整授权说明，档位含义：
  - **免费使用** —— 当前查得正文可公开分发；仍须核对所用语言版本、适用人群和机构要求，不能据此断言中文版已完成临床验证。
  - **免费 · 需注册或引用** —— 免费使用有注册、培训、引用或非商业场景等条件，须逐条遵守。
  - **免费 · 需申请许可** —— 不收费或可能不收费，但必须先取得权利方许可。
  - **商业授权 · 正文待填** —— 平台只保留题型、分值和判读结构，不分发正文；须取得授权后复制模板并录入正式版本，填完前系统禁止发布。
  - **授权未标注 / 使用前请核对授权** —— 授权条款不明确，正式研究前请核对权利方和正式版本。
  - 自建的问卷标为 **自有内容**；创建者仍须保证自己拥有内容权利。
- 许可标签只说明内容使用条件，不代表量表适用于所有患者或可由未培训人员使用。来源文献、正式中文版、伦理审批、评估者培训和机构流程仍需由研究团队核对。
- 「量表目录」还收录受版权、培训、特定版本或复杂规则限制的工具（如 MMSE、MoCA、APACHE II、Caprini、SF-36/SF-12、EQ-5D、EORTC QLQ-C30 等）。部分已有安全的结构模板，部分仅有目录元数据；以卡片和详情页说明为准。
- 内置模板受保护以保证多研究间定义一致；需要改动时点「创建副本」，副本会保留来源与授权说明。
- 卡片右上角的 ☆ 可把常用量表收藏起来，点亮的量表会出现在工作台「我的常用」里，一键进入、
  一键发布；工作台还会列出「最近打开」的量表。收藏只记在这台电脑的浏览器里（本地存储），
  换机器或清理浏览器数据即消失，不会写进调查数据库。

## 四、导入自己的量表

「量表库 → 导入量表」（或工作台快捷入口）支持上传后自动识别题干与选项，识别结果一律进入
**校对页**，逐题确认后才入量表库。

| 文件 | 说明 |
|---|---|
| Excel `.xlsx` / CSV | 识别最准。建议先下载页内模板，把题干、选项、分值、维度、反向计分、是否必答填好 |
| Word `.docx` / 文本型 PDF | 自动识别题干与选项；扫描版 PDF 无法取文字，请改用模板或截图 |
| TXT | 按行识别题号与选项 |
| 图片 `.jpg` / `.png` | 走服务器本机 OCR，**目前仅 macOS 服务器支持**（系统原生 Vision）；其它系统会提示改用模板或对照原图手工录入 |

旧版 `.doc` / `.xls` 请先在 Office 中另存为 `.docx` / `.xlsx` 或 `.csv`。

## 五、自制问卷与计分配置

「工作台 → 自制问卷 / 量表」提供单选、多选、下拉单选、数字填空、单行填空、多行填空、
滑块评分、时间、日期等题型，可配置：

- **维度**：把条目归入子量表，分别计算维度分。
- **反向计分**：条目分值翻转后参与总分。
- **分级判读**：设置分数区间对应的结论与建议（如 PHQ-9 的轻/中/重度），提交后自动判定并统计分布。
- **条件跳题**：按前一题答案跳过后续题目。
- **不计入总分**：人口学等辅助题可标记为不参与计分。
- **不适用选项**：把某个选项勾选「不适用」后，选它的这道题既不计分，也不进入总分与维度分的
  分母。ODI、WOMAC 这类「允许跳过与本次无关条目」的量表就靠它折算百分分——跳过一题不会
  被当成 0 分而低估障碍程度。
- **数值分档**：数字题可写「小于 X 记 A 分、B–C 记 D 分」，用于按实测秒数、化验值计分
  （如 SPPB 步速、Child-Pugh 胆红素）。
- **具名公式**：MELD / MELD-Na / Glasgow-Blatchford / IPAQ 的 MET-min/周 / QuickDASH 等
  需要按公式换算的量表，内置为固定公式，不接受自定义表达式。
- **安全预警条目**：涉及自伤等条目可标记，便于回收时优先关注。

## 六、发放与填写

1. 在量表详情页点「发布为调查」，设置调查名称、目标样本量、截止时间、是否匿名、
   是否记录 IP 与设备、是否提交后向受试者展示结果、是否需要知情同意。
2. 生成链接与二维码：可复制链接、下载或打印二维码，贴在诊室病房也可直接扫。
3. 受试者手机端填写：按维度分节显示，页面顶部有常驻进度条（滚动到题目中段也能看到
   「第几节 / 已答几题」）；单选题选中后会自动定位到下一道待答题，本节答完时「下一节」
   会提示可以进入下一节；填到一半退出会自动存草稿到浏览器本地，重新打开同一链接可继续
   填写或清空重填；提交前有核对页。
4. 达到样本量或截止时间后自动停止回收；也可在数据看板的「设置」里手动关闭（数据保留）。

## 七、数据与统计

「发放与数据」进入某个调查的看板，包含概览、结果描述、数据表、统计、图表、数据质量、随访等标签：

- **结果描述**：把本次回收的数据自动写成可直接引用的中文句子（样本量、总分均值±标准差与
  95%CI、分级构成、Cronbach α、组间比较、作答质量），可直接复制或打印/另存为 PDF，
  按需修订后写入论文「结果」部分。样本量不足、检验无法完成时会明确说明，不会给出伪数值。

- 描述统计：均值、标准差、中位数、四分位、偏度、峰度。
- 总分与维度分分布、分级判读人数与占比。
- 信度：Cronbach α、校正条目总分相关（CITC）、分半信度。
- 关系与组间：相关矩阵、独立样本 t 检验、单因素 ANOVA（含事后两两比较）、卡方检验，
  分布明显偏离正态时提供非参数检验（Mann-Whitney / Kruskal-Wallis）。
- 数据质量：自动检测作答时长异常、直线作答、重复 IP 等可疑样本。
- 回归与因子分析请在导出后用 SPSS/R 完成（看板会提示偏度阈值等判读注意点）。

「随访研究」支持同一受试者多时点（基线、1 个月、3 个月…）：按受试者编号自动配对，
输出配对 t 检验、Wilcoxon 符号秩检验与随访宽表。

## 八、数据导出

数据看板提供四种导出：

- **CSV（文字）**：选项以文字呈现，便于人工查看与归档。
- **SPSS 数值版 CSV**：选择题导出为分值，多选题拆成 0/1 虚拟变量，可直接导入 SPSS/R。
- **变量说明（codebook）**：变量名与题干、选项编码对照，用于在 SPSS 里设置变量标签。
- **JSON**：包含量表定义与答卷的完整结构化导出。

平台不生成 `.sav` 二进制文件；需要 `.sav` 时，用「SPSS 数值版 CSV + 变量说明」在 SPSS 中
一键导入并贴标签即可。

## 九、备份与恢复

「系统设置 → 数据备份与恢复」（仅管理员可见）：

- **立即生成备份**：用 SQLite 的 `VACUUM INTO` 生成自包含的单文件快照（已合并 WAL），
  保存在与数据库同级的 `backups/` 目录，返回文件大小、`PRAGMA integrity_check` 结果与
  SHA-256 校验和。请把快照文件和校验和一起留存。
- **下载**：备份列表每行都有下载链接，可复制到移动硬盘或院内存储。
- **恢复**：可从列表选择服务器上的快照，也可上传本地下载的 `.sqlite` 备份文件（换机、
  误删数据时用）。恢复前会重新校验文件格式、完整性与必备数据表，校验和不匹配会拒绝执行。
- 恢复是**整体覆盖**，覆盖后新产生的答卷无法找回；因此执行前系统会自动为当前数据生成一份
  `pre-restore` 快照，万一恢复错了还能再恢复回去。
- 恢复成功后所有登录会话失效，需要重新登录（用户与权限也来自该快照）。

## 十、部署与合规建议

- 公网发放请使用域名 + HTTPS（Nginx/Caddy 反向代理），并配置访问日志与定期自动备份。
- 涉及个人健康信息时：启用匿名模式、关闭 IP 与设备采集、优先院内网络部署，
  按《个人信息保护法》要求最小化采集并留存知情同意记录。
- 开展涉及患者的研究前，请完成伦理审查与知情同意；平台支持在问卷前强制展示知情同意并留痕。
- 定期在系统设置中生成备份，并把快照文件与校验和存放在与服务器不同的介质上。

## 十一、常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动失败并提示端口被占用 | 换端口：`PORT=8080 node server.js`；不要改用旧地址扫码 |
| 手机扫码打不开页面 | 服务只监听本机。用 `MEDSCALE_LAN=1` 或 `启动平台.command` 启动，并使用命令行显示的局域网地址 |
| 首页没有注册入口 | 「谁能开账号」被设为「关闭自助注册」。需要开号请改为凭邀请码注册并由管理员生成邀请码，或由管理员在「用户管理」直接创建账号 |
| 注册时提示邀请码无效／已过期／次数用完 | 该码已被用完、过期或吊销，请让管理员重新生成一张 |
| 上传图片没有识别出题目 | 图片 OCR 依赖 macOS 服务器；非 macOS 请改用 Excel/CSV 模板或对照原图手工录入 |
| 扫描版 PDF 识别不出内容 | PDF 仅支持可选中文字的内容，扫描版请改用模板 |
| 想改内置量表的条目 | 内置模板受保护，点「创建副本」后编辑副本 |
| 量表卡上写着「商业授权 · 正文待填」 | 该量表受版权保护，平台只内置题型、分值、维度与判读规则，条目文字需按你取得的授权版本填写：先「创建副本」，在编辑器里把每道题的题干和选项替换成授权原文；填完前系统会提示剩余题数并禁止发布 |
| 恢复后发现数据「变旧」了 | 恢复即回滚到快照时刻；系统已自动生成 `pre-restore` 快照，可再次恢复回去 |
| 改了管理员密码后所有人都掉线 | 正常行为：口令修改会失效全部会话，重新登录即可 |

## 十二、开发与测试

```bash
npm test      # 对比度、无障碍、量表数据、端口策略、口令安全、权限、备份恢复、接口与前端流程等全套用例
npm run audit # 布局与看板核查（会自行拉起临时实例；首次需 npx playwright install chromium）
```

测试只额外用到 jsdom / playwright（都记在 `devDependencies`），运行期仍然零第三方依赖；
每个用例都会写入独立的临时数据库。

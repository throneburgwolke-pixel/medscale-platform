# 医学量表与问卷平台 · 使用说明

## 一、启动平台

**方式一（macOS 推荐）**：双击 `medscale/启动平台.command`，浏览器会自动打开。

**方式二（命令行）**：

```bash
cd /Users/fuzhuzhijia/Documents/Codex/2026-10-05/new-chat-3/medscale
node server.js
```

启动后命令行会显示：

```
  本机访问：   http://localhost:5173
  局域网访问： http://192.168.1.5:5173   （手机扫码填写需用这个地址）
  管理员密码： （首次启动随机生成，见启动日志或 data 目录下的「管理员初始口令.txt」）   ⚠️ 初始口令，请登录后在"系统设置"中修改
```

- **首次使用请先修改密码**：登录后 →「系统设置」→ 修改管理员密码。
- 关闭窗口（或按 `Ctrl + C`）即停止服务，数据不会丢失。
- 换端口：`PORT=8080 node server.js`

## 二、发放问卷（最常用的流程）

### 第 1 步：选择题量

进入「量表库」→ 浏览或搜索（如输入"睡眠"）→ 点某个量表的 **查看条目**。

### 第 2 步：发布

在量表详情页点 **发布为调查**，弹窗中设置：

| 选项 | 说明 |
|---|---|
| 调查名称 | 受试者看到的标题，例如"门诊睡眠质量调查" |
| 目标样本量 | 达到数量后自动停止回收（可留空） |
| 截止时间 | 到期自动停止（可留空） |
| 匿名收集 | 建议勾选；答卷只记录随机编号 |
| 提交后展示结果 | 勾选后受试者能看到自己的得分与解释（筛查类建议勾选） |
| 记录 IP 与设备 | 用于质控（排查重复提交）；涉及隐私时可取消 |

点「生成链接与二维码」即完成发布，自动跳转到数据看板。

### 第 3 步：发给受试者

- **点「二维码」**：受试者用微信/相机扫码即可填写（无需安装 App）
- **点「复制链接」**：粘贴到微信、短信、公众号文章
- **打印二维码**：在弹窗中点「打印/另存二维码」，可贴在诊室、病房

> **手机与电脑需要连同一个 WiFi（局域网）**。如果电脑显示的是 `localhost`，请改用命令行显示的"局域网访问"地址。

### 第 4 步：查看回收进度

「发放与数据」→ 点调查名称进入数据看板，可实时看到回收份数、分级分布、图表。
不再需要数据时，在「设置」标签页点 **已关闭** 即可停止回收（数据保留）。

## 三、自制问卷 / 量表

### 从空白开始

首页点 **＋ 新建空白问卷**，或「量表库」→ **＋ 空白问卷**。

### 从模板改（推荐）

找到相近的模板 → **创建副本** → 进入编辑器修改。改动只影响副本，原模板不受影响。

### 编辑器使用要点

| 操作 | 位置 |
|---|---|
| 改题干 | 题目文本框直接输入 |
| 改选项与分值 | 选项行左侧填文字、右侧填分值（分值用于自动计分） |
| 增加/删除选项 | 选项行右侧「×」；下方「＋ 添加选项」 |
| 调整顺序 | 题目右上角 ↑ ↓ |
| 复制题目 | 题目右上角「复制」 |
| 必答 / 选填 | 勾选「必答」 |
| **不计入总分** | 人口学题（性别、年龄等）务必勾选，否则会被加进总分 |
| 反向计分 | 如 PSS-10 的第 4、5、7、8 题勾选「反向计分」 |
| 所属维度 | 先在上方"维度设置"添加维度，再在题目上选择 |
| 分级解释 | 右侧"计分设置 → 分级解释"，填"≤ 分值 → 判读 → 处理建议" |
| 知情同意 | 右侧"知情同意"，勾选后受试者必须先同意才能作答 |
| 检查效果 | 右上角「预览填写效果」 |

改完点 **保存**（右上角或右下角）。

### 计分设置怎么选

- **各题求和**：大多数量表（PHQ-9、GAD-7、ISI…）
- **各题均分**：条目数不同或需要 1–5 分制均分时（如满意度）
- **不计分**：纯调查性问卷（只做描述统计）
- **总分倍数**：WHO-5 原始分 0–25 需乘 4 变成 0–100，就填 4
- **反向计分最大分**：该题选项的最大分值（如 0–4 计分填 4）

### 可用的题型

单选、多选、下拉单选、数字填空（可设单位与范围）、滑块评分（如疼痛 0–10）、单行/多行填空、时间、日期。

## 五、备份与数据安全

1. **备份**：把 `medscale/data/app.db` 复制到移动硬盘或院内网盘即完成备份（建议每周一次；研究关键期可每天一次）。
2. **迁移**：在新电脑安装 Node.js，把整个 `medscale` 文件夹拷过去即可继续用（密码、量表、数据都在里面）。
3. **删除**：删除调查会同时删除其全部答卷且**不可恢复**，操作前请先导出。
4. **隐私**：默认匿名；如收集了姓名/住院号，建议另建编号对照表并单独保存。

## 六、常见问题

**Q1 手机扫码打不开？**
手机与电脑要在同一 WiFi；把链接里的 `localhost` 换成命令行显示的局域网 IP（如 `http://192.168.1.5:5173/s/xxxx`）；检查电脑防火墙是否拦截 Node。

**Q2 忘记管理员密码？**
命令行重设：`node -e "const {DatabaseSync}=require('node:sqlite');const db=new DatabaseSync('data/app.db');db.prepare(\"update settings set value='你的新密码' where key='admin_password'\").run();"`（在 `medscale` 目录下执行、把「你的新密码」换成自己想用的口令，之后用它登录并立即在「系统设置」里再改一次）。

**Q3 想让受试者看到结果，但不想让所有人看到？**
发布时勾选"提交后向受试者展示结果"；不勾选则只显示致谢页。数据看板始终只对管理员开放。

**Q4 量表条目需要改动，但又想保留原版？**
用"创建副本"改副本。原始内置模板永远保持完整，便于对照与引用。

**Q5 数据能不能放在医院服务器上给全科室用？**
可以。把 `medscale` 文件夹拷到服务器，`node server.js` 启动并用 IP/域名访问；建议由信息科配置 HTTPS 与定期备份。若需多人各自账号，请告知，我可以加上多用户与权限模块。

**Q6 统计结果能不能直接贴到论文里？**
平台输出的均值±标准差、α、CITC、t/F/χ²、p 值、效应量等可直接用于论文；建议同时保留**原始数据导出**，以便审稿人或统计老师复核。

**Q7 支持哪些量表可以自己加？**
任何量表都可以用编辑器录入（题干、选项、分值、维度、反向计分、分级）。需要授权/培训的量表（MMSE、MoCA、HADS、SF-36、QLQ-C30 等）请先取得授权，平台已在内置"授权提示"中列出。

## 十、跳题逻辑与随访研究（2026-10-07 新增）

### 10.1 跳题逻辑（"选无则跳过后续"）

**在编辑器中设置**：打开量表编辑器 → 找到作为"触发条件"的单选题 → 题目卡片下方「跳题逻辑」→ 点「＋添加跳题规则」→

1. 勾选**触发选项**（可多选，如勾"无""从不"）
2. 选择动作：**跳至**（跳到后面某一题）或**结束问卷**（后面题目全部跳过）
3. 若选"跳至"，再指定目标题号

支持一题多条规则，例如：选"无"→结束问卷；选"偶尔"→跳到第 5 题。

**受试者侧表现**：命中规则后，被跳过的题目立即从页面消失，顶部提示"已跳过 N 题"；提交时**不会**要求作答被跳过的题目。

**数据处理**：

- 被跳过的题目**不计入总分与维度分**，完成度按"实际需要作答的题目"计算
- 报告中该题按"未作答/跳过"统计，可与真实缺失区分（导出数据中该题为空）
- 跳题规则保存在问卷定义中，**历史答卷按当时规则重新判定**，口径一致

### 10.2 随访研究（多次测量与配对检验）

**创建**：左侧菜单「随访研究」→ 新建 → 选择题量、填写研究名称、设置时点（默认 基线 / 1个月 / 3个月，可增删改）→ 选择编号方式：

- **系统自动分配**：受试者首次填写后显示编号（如 S-0001），请其记录，后续时点填写同一编号
- **受试者自填编号**：如住院号、研究编号（需研究方统一管理）

创建后每个时点各自生成**独立链接与二维码**，可分别发放。

**受试者编号与防重复**：填写页会提示填写编号；同一编号在**同一时点**重复提交会被拒绝，避免破坏配对。

**分析与导出**（随访详情页）：

| 内容 | 说明 |
|---|---|
| 各时点得分 | 每个时点的 n、均值±SD、中位数、范围、判读分布 |
| **配对比较** | 只纳入"两个时点都完成且编号一致"的受试者：配对 t 检验、**Wilcoxon 符号秩检验**（偏态/等级资料）、变化值 Δ 与 95%CI、Cohen's d；多时点两两比较同时给出 **Bonferroni 校正 p 值** |
| 随访完成情况 | 各时点例数、完成全部时点人数、随访完成率（失访分析） |
| **导出随访宽表** | 一行一个受试者，列为各时点总分/维度分/分级 + Δ 值，可直接做**重复测量方差分析（RM-ANOVA）** |

> 论文建议：报告各时点例数与失访原因；≥3 个时点建议用宽表在 SPSS/R 中做重复测量方差分析或混合效应模型（平台已提供 Wilcoxon/Friedman 类非参数替代与两两比较）。

## 十一、导入自己的量表（2026-10-07 新增）

**入口**：工作台「导入自己的量表」卡片，或量表库右上角「📥 导入量表」。

### 11.1 支持的格式与识别方式

| 格式 | 识别方式 | 效果 |
|---|---|---|
| **Excel .xlsx** | 按表头识别（题干/题型/选项1…/分值1…/维度/必答/反向计分） | 最佳，识别准确 |
| **CSV / TXT** | 同上；也支持纯文本启发式识别 | 最佳（推荐配合模板） |
| **Word .docx** | 按段落识别题干与选项（A. / B. / ① / 1) 等），分值可写"完全没有（0）" | 好 |
| **PDF** | 提取文本流（**仅文本型 PDF**，扫描件不行） | 中等，需仔细校对 |
| **图片 .jpg/.png** | 服务器本机调用 macOS 原生 OCR（Vision）识别中文 | 取决于清晰度；不可用时可对照原图手工录入 |

> 旧版 `.doc` / `.xls` 请先在 Office 中另存为 `.docx` / `.xlsx` 或 `.csv`。

### 11.2 三种用法

1. **最省事：用模板**——点「下载 Excel/CSV 模板」，在 Excel 里填写题干、选项、分值（还可填维度、必答、反向计分），保存后上传，识别率 100%。
2. **直接传原文件**——Word/PDF/图片直接上传，系统自动识别题目与选项。
3. **识别 + 校对**——无论哪种方式，都会进入**校对页**：逐题可改题干、切换题型、编辑选项（每行一个，可写 `完全不会|0` 指定分值）、标记"不计分"、删除或新增题目；右侧可查看原始文本或上传的图片对照。

确认后点「保存到量表库」（或「保存并发布调查」），导入的量表**与内置量表功能完全一致**：可发布、扫码回收、自动计分、信度分析、组间/随访统计、CSV/SPSS 导出。

### 11.3 注意事项

- 文件大小上限 20 MB；解析在**本机完成**，不会上传到任何第三方服务器。
- 导入后请核对：题干措辞、选项顺序与分值、是否需要"反向计分"、是否需要"不计入总分"（如性别年龄题）。
- 混合型问卷（人口学题 + 量表题）请把人口学题勾选「不计分」，否则会被算进总分。
- 量表授权请自行确认（平台会把来源标记为"用户导入"）。

## 十五、打不开网站怎么办（2026-10-07 第三次更新）

### 15.1 最常见原因

1. **打开的是旧进程的地址**：如果之前启动过多个版本，旧进程仍占着 5173 端口，它没有最新功能（例如注册会报错）。此时页面"看起来能打开"，但点注册/新功能会失败。
2. **服务没有在运行**：网页需要后台的 Node 服务在运行，关掉那个终端窗口或重启电脑后，服务就停止了，需要重新启动。

### 15.2 一步到位的解决方法

1. 双击 **`停止平台.command`**：自动查找并停止所有本平台的服务进程，释放端口。
2. 双击 **`启动平台.command`**：自动启动服务，**端口被占用会自动顺延**，并**自动打开正确的网址**。

> 新版本会把实际访问地址写入 `medscale/data/运行地址.txt`，启动脚本读取它后再打开浏览器，因此不会再出现"打开的地址不是当前服务"的问题。

### 15.3 手动方式（命令行）

```bash
cd /Users/fuzhuzhijia/Documents/Codex/2026-10-05/new-chat-3/medscale
node server.js          # 启动（端口被占用会自动 +1 顺延，控制台会打印实际地址）
```

停止：`pkill -f "medscale/server.js"`，或在终端按 `Control + C`。

### 15.4 判断是否是最新版本

浏览器打开后进入「量表库」→ 右上角应有「📥 导入量表」按钮；登录页应有「注册」标签页。若没有，说明连到的是旧进程，按 15.2 处理。

### 15.5 关于"量表库接口不存在"

出现这个提示的原因是：**打开的是旧实例**（例如 5173 上几天前启动的进程），它没有后来新增的 `/api/public/scales`（公开量表库）接口。

本次已做三项改进：

1. **前端自动识别旧后端**：连到旧版本时会直接显示醒目提示页，列出解决步骤与最新版候选地址，不再出现难以理解的"接口不存在"。
2. **公开量表库降级显示**：即使接口不可用，也会用内置的静态清单展示 38 个常用量表，并提示"当前服务版本较旧"。
3. **一键清理旧实例**：
   - `启动平台.command` 现在会**先自动停止本目录下的所有旧实例**（按进程工作目录精确匹配，不会误杀其它 Node 程序），再启动新实例；
   - 新增 `停止平台.command` 可单独停止全部实例并释放端口。
   因此以后只需双击一次「启动平台」，就不会再打开到旧版本。

## 十七、故障修复：发布调查后"页面加载失败"（2026-10-07 第五次更新）

### 17.1 现象与原因

**现象**：用某个量表发布调查后，打开数据看板出现「页面加载失败：The string did not match the expected pattern.」（Safari 提示）或「Failed to execute 'addColorStop' ... could not be parsed as a color」（Chrome 提示）。

**根本原因**：数据看板"分级分布"图表的颜色兜底值被写成了 **CSS 变量** `var(--grad-teal-2)`。
- CSS 变量只能在样式表里使用，**Canvas 绘图 API 无法解析**；
- `CanvasGradient.addColorStop()` 收到无法解析的颜色时**直接抛异常**；
- 该异常发生在页面渲染过程中，被整体捕获后显示为"页面加载失败"，因此**整页不可用**（而不只是图表不显示）。

只要量表设置了分级判读（大多数量表都有），看板概览页就会绘制该图表，因此几乎必现。

### 17.2 修复内容

1. **修正颜色取值**：兜底色改为十六进制 `#10766b`；同时把图表函数中残留的 6 处 `var(--mute-*)` 网格线/坐标轴颜色全部改为十六进制色值。
2. **分类配色表统一为十六进制**：原先 `CAT_COLOR` 混用了 CSS 变量（如 `var(--violet)`、`var(--grad-teal-4)`），虽然用于卡片样式没问题，但一旦传入 Canvas 图表就会再次触发同类错误，现已全部改为等价的十六进制色值。
3. **新增 `safeColor()`**：任何要送进 Canvas 的颜色先做校验——`var(...)` 或 `CSS.supports('color', ...)` 判定非法时自动回退到安全色，**从源头杜绝这类错误**。
4. **新增 `safeDraw()` 容错**：所有图表绘制（柱状图、直方图、折线图）都包裹在 try/catch 中，即使将来某个图表绘制失败，也只影响该图表，**不会再导致整页加载失败**。

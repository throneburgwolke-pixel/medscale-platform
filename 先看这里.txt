医学量表与问卷平台 · 使用入口
====================================

【每天怎么用】
  1) 双击「启动平台.command」→ 浏览器会自动打开（默认端口 5184）
  2) 用完后，双击「停止平台.command」即可关闭服务
  3) 若双击启动后提示端口被占用：先双击「停止平台.command」，再双击「启动平台.command」

【手机扫码填写】
  启动后在终端窗口里会打印局域网地址（如 http://192.168.1.5:5184）。
  受试者与本机连同一个 WiFi，扫码或输入该地址即可填写。
  若已配置公网隧道（cloudflared），外部访问用的是域名，不带端口。

【默认账号】
  管理员：admin（首次使用请在「系统设置」中修改密码）
  已有研究者账号：程倩倩

【文件夹里都有什么】
  server.js / core/ / lib/ / public/   ← 程序本体（不要删除或改名）
  data/                                ← 数据库（全部量表、调查、答卷、账号都在这里，
                                          建议定期复制留备份）
  docs/                                ← 全部文档
      ├─ 使用说明.md                    ← 日常使用看这份
      ├─ 量表使用手册.md                ← 78 个量表的使用方法与来源文献
      ├─ 量表清单.md                    ← 量表与条目一览（含需授权量表的获取途径）
      ├─ 方案与建议.md                  ← 平台设计、统计方法学与合规建议
      ├─ 界面截图/                      ← 各页面截图
      └─ 开发期文档/使用说明-开发期详细版.md
  deploy/                              ← 部署到服务器用的配置（Docker / Nginx / systemd 等）
  test/                                ← 自动化测试（改代码后运行 npm test 验证）
  版本历史.bundle                       ← 开发过程的完整 Git 版本历史（44 次提交，可恢复任何历史版本）
  README.md                            ← 面向开发者的工程说明（环境变量、测试、约定）

【版本历史怎么恢复】
  在终端执行：
    git clone 版本历史.bundle medscale-history && cd medscale-history
  即可得到一个包含全部提交记录的代码仓库。

【备份建议】
  把 data/app.db 复制到别处即可完成备份（研究关键期建议每天一次）。
